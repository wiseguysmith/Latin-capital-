## 1. Pilot design

- **Cohort A (Phase 0, manual):** 3–5 businesses, mixed types (≥1 BT-SME, ≥1 BT-RE-DEV, ≥1 BT-STARTUP or BT-AR). Purpose: calibrate anchors, checklists, workbook.
- **Cohort B (Phase 1–2, in-product):** 10–20 businesses (CRF §22 target), recruited via partner networks and provider referrals; explicit pilot agreement (feedback, data use consent, possibly discounted/free assessment — OQ-01).
- **Cohort C (Phase 3):** subset of B with approved assessments + 3–5 design-partner providers (≥1 private-credit fund, ≥1 family office; bank optional).

## 2. Recruitment & expectations

Pilot agreement states plainly: readiness assessment only; no funding promise; data use scope; feedback sessions (2 per borrower); free/discounted pricing disclosed (D-15 firewall reaffirmed — pricing never varies with score). Provider design partners commit to: mandate profile, reviewing ≥2 packages, outcome + decline-reason reporting (37 taxonomy), monthly feedback call.

## 3. Pilot script (per borrower)

1. Intake + screening (51) → 2. onboarding call (expectation setting) → 3. evidence sprint with weekly check-ins → 4. assessment production (52/53) → 5. results + action-plan session → 6. remediation window (4–6 weeks) → 7. optional reassessment → 8. (Cohort C) consent + publication + provider review → 9. exit interview.

## 4. Metrics & targets (from CRF §22.1; baselines from Phase 0)

| Metric | Pilot target (initial; recalibrate after cohort A) |
|---|---|
| Time to readiness package | median ≤45 days cohort B (vs Phase-0 baseline); P90 tracked |
| First-pass completeness | ≥60% cohort B end (expect low start) |
| Reconciliation exception rate | tracked; resolution median ≤7 days |
| Remediation conversion | ≥40% of "Developing"+ borrowers move up ≥1 band after plan |
| Override rate | <15% of assessments; all justified; no direction bias |
| Provider time-to-screening | median ≤10 business days from access |
| Diligence-request reduction | qualitative in pilot: providers report fewer repetitive requests (survey) |
| Outcome funnel | ≥3 EOIs across cohort C; ≥1 external underwriting start |
| Fairness/access | no unexplained completion/score gaps by segment (small-N caution — CRF §21 weak-outcome-data honesty) |
| AI quality (Phase 2) | 31 §8 targets; reviewer-time reduction ≥30% |

## 5. Feedback machinery

Weekly ops retro (SOP friction log); borrower interviews at results + exit; provider calls monthly; all feedback triaged into backlog (71 §4) or methodology proposals (20 §10); pilot journal maintained (documentation of anchor decisions → feeds model v1.1 calibration and 63 template hardening).

## 6. Stop / pause conditions

Immediate pause: any Sev-1 (score integrity, data leak, restricted-flag exposure); counsel withdraws comfort on perimeter (GATE-07); evidence of platform language being used as funding promises by any party (correct + retrain before resuming). Pilot end: exit criteria of Phase 3 gate (75 §5) or 2 consecutive months without progress → strategy review.

## 7. Pilot honesty rules (CRF §21)

Publish validation limits with any pilot results; conservative claims only ("pilot indicates", never "proven"); no marketing of scores as predictive; recalibrations documented transparently in 05.
